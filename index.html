ERROR LIBRARY / 02

ارورها را قابل فهم کنیم

کاربر کد یا متن خطا را می‌فرستد؛ دستیار مفهوم آن را توضیح می‌دهد، علت‌های محتمل را مرتب می‌کند و راهکارها را مرحله‌به‌مرحله آموزش می‌دهد. نمونه‌های زیر صرفاً موضوعات قابل پشتیبانی‌اند، نه تضمین رفع هر خطا.

مشکل نرم‌افزاری دارید؟

به درخواست شما، دستیار خطا را بررسی و مسیرهای رفع مشکل را پیشنهاد می‌دهد. اگر اقدام حساس باشد، قبل از اجرا درباره نسخه پشتیبان و اجازه مسئول هشدار می‌دهد.

مشکل سخت‌افزاری دارید؟

نشانه‌ها را توصیف کنید؛ آموزش اولیه متناسب با شما ارائه می‌شود. برای باز کردن دستگاه یا کارهای خطرناک، ارجاع به فرد متخصص.

Code 1 / Device error
Windows / app crash
